# yayca

## Īsas atbildes uz jautājumiem

- **Kas ir cmd komandas rindā?**  
  Komandu rinda (Command Line Interface) ir tekstuāla saskarne, kurā lietotājs ievada komandas, lai veiktu dažādas darbības.

- **cd ..**  
  Pārvieto vienu līmeni augstāk direktoriju struktūrā.

- **cd Downloads**  
  Pārvieto uz "Downloads" direktoriju.

- **ls vai dir**  
  `ls` (Linux/Mac) vai `dir` (Windows) parāda direktorijā esošos failus un mapes.

- **read the guide**  
  Izlasi dokumentāciju vai ceļvedi, lai saprastu, kā lietot rīku vai projektu.

- **Repository name**  
  Krātuves (repository) nosaukums, piemēram, "yayca".

- **Initialize this repository with README**  
  Izveido jaunu Git krātuvi un pievieno sākotnējo README failu.

- **Clone or download**  
  Lejupielādē vai klonē Git krātuvi uz lokālo datoru.

- **git clone http ...**  
  Klonē attālo Git krātuvi uz lokālo datoru.

- **commit**  
  Saglabā izmaiņas lokālajā Git krātuvē.

- **git push**  
  Nosūta lokālās izmaiņas uz attālo Git krātuvi.

- **git pull**  
  Lejupielādē izmaiņas no attālās Git krātuves uz lokālo.

- **pull request**  
  Pieprasījums apvienot izmaiņas no vienas zara (branch) uz citu, parasti galveno zaru.
